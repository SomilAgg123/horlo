# Contributing

Use Node.js 24, install with `npm ci`, and start the app with `npm run dev`. All changes should go through a focused pull request.

Before opening a PR, run `npm run check` and `npm run format:check`. Include meaningful tests when changing storage or a user journey. UI changes should include desktop and mobile screenshots. CI runs the production build and browser tests.

Keep the demo self-contained. Do not add credentials, real user records, backend dependencies, analytics, or hotlinked product photography. Document manufacturer sources when changing sample specifications, and use original or appropriately licensed artwork.

The default collection and public example should remain usable without accounts, network APIs, or browser state from an earlier visit.
